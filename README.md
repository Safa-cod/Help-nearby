# Help Nearby

**Help Nearby** is a simple web-based platform designed to connect people who need help with people who are willing to provide assistance. The main goal of this project is to make it easier for people to request and offer help within their local community.

Users can create help requests for different situations, such as **blood requirements, medicine needs, elderly assistance, volunteer support, and emergency transportation**. Each request contains important information such as the type of help, description, location, contact information, and urgency level.

The system also allows volunteers to view available requests and **accept a request** when they are ready to help. After the required help has been provided, the request can be marked as **completed**. This makes it easy to track the current status of each request.

The project uses **HTML, CSS, and JavaScript** for the frontend and **FastAPI with Python** for the backend. A **REST API** is used to communicate between the frontend and backend. The application uses **SQLite** to store and manage help request information.

### Main Features

* Create and post help requests
* Select different types of help
* Add location and contact information
* Set request urgency as Low, Medium, or High
* View all available help requests
* Accept an open request
* Mark an accepted request as completed
* Delete help requests
* Filter requests by status
* Store request data in a database
* Use REST API for frontend-backend communication

### Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, FastAPI
* **Database:** SQLite
* **API:** REST API
* **Development Tool:** Visual Studio Code

### Project Purpose

The purpose of Help Nearby is to provide a simple digital platform where people can quickly communicate their needs and find others who are willing to help. The project demonstrates how a frontend, backend, REST API, and database can work together to create a useful real-world web application.
